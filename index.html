How it works

  1. Detect people and vehicles in every frame with a COCO object detector (MediaPipe, running on your GPU or CPU).
  2. Track each one across frames so every person and vehicle is counted once.
  3. Background subtraction marks what is moving, so parked cars are ignored.
  4. Rule: if a moving vehicle enters the crosswalk while a pedestrian is already on it, it did not yield. A vehicle that waits near the crossing first counts as yielded.
  5. Evidence: each violation saves the frame and a zoomed crop of the vehicle, and you can try to read its number plate (Tesseract OCR).
